# Changelog

All notable changes to CodeGuard AI will be documented in this file.

## [1.0.0] - 2026-11-12

### Added
- Initial public preview of CodeGuard AI.
- Self-hosted GitHub pull-request review for Java and Spring Boot.
- Evidence-based finding labels and configurable merge policy.
- Repository impact analysis and test-quality analysis.
- Deterministic security and code-quality checks.
- Suggested fixes with an explicit Apply Fix workflow.
- Docker-based sandbox test validation.
- Review history and dashboard.

### Documentation
- Added public README and product screenshots.
- Added a runnable TestOutcome sample module with automated tests.
